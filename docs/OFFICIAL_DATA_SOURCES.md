## 2. Data Attribution & Integrity Enforcement

1. **Clear Provenance:** Every subcategory and indicator screen must display the exact name of the publishing organisation and dataset title.
2. **Standardised Reporting Years:** Data points must be tagged with the exact observation year (e.g. 2024, 2023, 2022). Annual statistical survey data must never be deceptively labeled "Real-time".
3. **No Incompatible Combinations:** Indicators with different units or methodologies (e.g. CPI 0-100 score vs HDI 0-1 score) must never be averaged or compounded into a false single index.
